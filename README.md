# Домашнее задание: урок 6. Пользователи, группы и права доступа в Linux

## Цель работы
Создать трёх пользователей и одну группу в операционной системе Linux, настроить права доступа к файлам и протестировать их работу, переключаясь между учётными записями.

## Шаг 1: Создание трёх пользователей

С помощью команды `useradd` с флагом `-m` (автоматическое создание домашней директории) были созданы три новых пользователя: `user1`, `user2` и `user3`. После создания для каждого пользователя командой `passwd` был установлен пароль — система запросила ввод пароля дважды для подтверждения корректности.

```bash
sudo useradd -m user1
sudo useradd -m user2
sudo useradd -m user3
sudo passwd user1
sudo passwd user2
sudo passwd user3
